# Rainfield 요약본 자동 생성기

원본 IM(PDF)을 올리면 **4~5장짜리 요약본 PPT**를 자동으로 만든다.

## 흐름

```
1 원본 업로드 → 2 하이라이트 → 3 내용 배치 → 4 생성
```

| 단계 | 하는 일 |
|---|---|
| 1 원본 업로드 | PDF를 읽어 핵심 데이터(사모사채개요·담보대출조건·사업일정·법인개요·재무제표 등)를 LLM으로 추출 |
| 2 하이라이트 | 왼쪽에 원본 페이지를 띄워두고 오른쪽에서 핵심 3가지 카드를 확인·수정 |
| 3 내용 배치 | A4를 좌·우 단으로 나눠 각 칸에 무엇을 넣을지 지정 (1페이지 / 2페이지) |
| 4 생성 | 레이아웃 틀에 값을 채워 PPTX 생성 → 다운로드 |

## 결과물 구성

표지 → 하이라이트 → 핵심요약(1~2장) → 연락처

## 로컬 실행

```bash
streamlit run summary_app.py --server.port 8502
```

`.env` 에 API 키를 둔다.

```
ANTHROPIC_API_KEY=sk-ant-...
```

## 배포 (Streamlit Cloud)

- Main file path : `summary_app.py`
- Secrets 에 `ANTHROPIC_API_KEY` 등록
  (`.env` 가 없으면 자동으로 secrets 에서 읽는다)

## 파일

| 파일 | 역할 |
|---|---|
| `summary_app.py` | 4단계 웹앱(UI) |
| `summary_pipeline.py` | 핵심데이터 추출 + 레이아웃 틀 채우기 |
| `engine_bits.py` | PDF 페이지 렌더·이미지 추출·서식 유지 텍스트 교체 |
| `extractors.py` | PDF/DOCX 텍스트 추출 |
| `claude_api.py` | LLM 호출·캐시·비용 로깅 |
| `layout/요약본 레이아웃.pptx` | 회사 요약본 레이아웃 틀 |

## 주의

- **레이아웃 틀이 목록을 정한다.** 3단계에서 고를 수 있는 항목(사모사채개요·담보대출조건·
  대출조건표·사업일정·법인개요·재무제표·조감도)은 `layout/요약본 레이아웃.pptx` 안의
  표·이미지 자리와 1:1로 붙어 있다. 항목을 늘리려면 레이아웃에 자리를 먼저 만들어야 한다.
- 원본에서 못 찾은 항목은 3단계 목록에 뜨지 않는다(없는 내용을 지어내지 않기 위함).
- 숫자·금액·비율·날짜는 원문 그대로 옮긴다. 반올림·추정하지 않는다.
